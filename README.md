# ReviewScheduler_afz


A basic python project for scheduling notes reviews and getting their respective metrics after each study session.

## Installation

To install with pip on macOS or Linux, run:

    python3 -m pip install reviewscheduler

To install with pip on Windows, run:

    py -m pip install reviewscheduler
